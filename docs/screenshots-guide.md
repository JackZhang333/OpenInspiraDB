# Mac App Store 截图规范指南

## 截图尺寸要求

Mac App Store 要求以下尺寸（至少提供 1 张，建议 3-5 张）：

| 尺寸 | 分辨率 | 用途 |
|------|--------|------|
| 16:10 | 1280 x 800 | 标准截图 |
| 16:10 | 1440 x 900 | 高清截图 |
| 16:10 | 2560 x 1600 | Retina 截图 |
| 16:9 | 1280 x 720 | 宽屏截图 |

**推荐尺寸**: 1440 x 900（兼容大多数 Mac 屏幕）

## 截图美化建议

### 视觉风格
1. **简洁干净**：关闭不必要的窗口和通知
2. **Dock 栏**：可以隐藏 Dock 栏保持整洁
3. **菜单栏**：确保菜单栏显示应用名称"意图集"
4. **主题一致**：使用浅色模式（或深色模式，保持一致）

### 示例数据准备
准备以下类型的示例图片（各 3-5 张）：
- 风景摄影（海滩、山脉、城市）
- UI/UX 设计截图
- 插画和图形设计
- 产品摄影
- 建筑摄影
- 人物/时尚摄影

### 推荐的数据来源
- Unsplash（免费高质量图片）
- 你自己创作的素材
- 确保有使用权，避免版权问题

## 截图制作步骤

### 方法一：使用系统截图工具

1. **设置窗口大小**
   ```bash
   # 可以使用 AppleScript 或手动调整窗口
   # 推荐尺寸：1440 x 900
   ```

2. **隐藏干扰元素**
   - 右键 Dock → 启用隐藏
   - 关闭通知中心
   - 关闭其他应用窗口

3. **截图快捷键**
   - `Cmd + Shift + 4` + 空格：截取特定窗口
   - `Cmd + Shift + 5`：打开截图工具栏

4. **检查截图**
   - 确认分辨率为 1440x900 或 1280x800
   - 确保图片清晰，无模糊

### 方法二：使用第三方工具

推荐工具：
- **CleanShot X**：专业的 Mac 截图工具
- **Shottr**：免费，支持标注
- **Xnapper**：美观的截图美化工具

上传 App Store Connect 时使用：

```
screenshot-1-main.png
screenshot-2-search.png
screenshot-3-detail.png
screenshot-4-tags.png
screenshot-5-import.png
```

**要求：**
- PNG 格式
- 72 dpi 或更高
- 无 Alpha 通道（可选）
- 文件名使用英文

## 注意事项

1. **版权问题**
   - 使用的示例图片必须有合法授权
   - 推荐使用 Unsplash 等免费可商用图片
   - 记录图片来源以备审核询问

2. **内容合规**
   - 避免截图中出现敏感内容
   - 确保所有示例图片适合所有年龄段

3. **真实性**
   - 展示的功能必须真实可用
   - 不要展示未实现的功能
   - AI 分析结果应该是真实的输出

4. **一致性**
   - 所有截图保持相同的设计风格
   - 使用相同的数据集
   - 保持窗口尺寸一致
