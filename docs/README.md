## 🚀 上架前执行清单

### 第一步：准备工作（1-2 天）

- [ ] **准备示例数据**
  - 下载 15-20 张高质量示例图片（推荐 Unsplash）
  - 图片类型：风景、UI设计、插画、摄影、建筑

- [ ] **部署法律文档**
  - 将 `privacy-policy.md` 部署到网站（如 GitHub Pages）
  - 将 `terms-of-use.md` 部署到网站
  - 记录两个 URL

- [ ] **准备截图**
  - 按 `screenshots-guide.md` 指南截取 3-5 张截图
  - 确保尺寸为 1440x900 或 1280x800
  - 保存为 PNG 格式

### 第二步：App Store Connect 配置（半天）

- [ ] **创建 App 记录**
  - 登录 [App Store Connect](https://appstoreconnect.apple.com)
  - 创建新的 macOS App
  - 填写 Bundle ID: `com.inspiradb.desktop`

- [ ] **填写 App 信息**
  - 名称：意图集
  - 副标题：AI 驱动的灵感图片管理工具
  - 类别：图形与设计
  - 参考：`app-store-metadata.md`

- [ ] **填写元数据**
  - 推广文本
  - 描述
  - 关键词
  - 支持 URL（隐私政策和使用条款的 URL）
  - 营销 URL（可选，可以是 GitHub 仓库）

- [ ] **上传截图**
  - 上传准备好的 3-5 张截图
  - 确保符合尺寸要求

- [ ] **填写审核信息**
  - 联系信息
  - 审核备注（参考 `app-review-guide.md`）
  - 演示账号：无需登录

### 第三步：构建和上传（半天）

- [ ] **准备构建**
  - 确认版本号（如 1.0.0）
  - 在 `package.json` 中更新版本

- [ ] **生成分发版本**
  ```bash
  npm install
  npm run icon:mac
  npm run dist:mas
  ```

- [ ] **上传构建**
  - 使用 Transporter App 上传生成的 .pkg 文件
  - 或在 Xcode 中组织上传

### 第四步：提交审核（半天）

- [ ] **最终检查**
  - 确认所有信息填写完整
  - 确认截图已上传
  - 确认构建已上传并显示

- [ ] **提交审核**
  - 在 App Store Connect 点击"提交审核"
  - 等待审核结果（通常 1-3 天）

## ❓ 常见问题

### Q: 我没有网站，怎么部署隐私政策？
**A**: 可以使用以下免费方案：
- GitHub Pages（推荐）
- GitLab Pages
- 将内容发布在 GitHub 仓库的 README 中

### Q: 截图可以用模拟数据吗？
**A**: 可以，但需要确保：
- 图片有合法使用权（推荐使用 Unsplash）
- 不包含敏感或不当内容
- 展示的功能真实可用

### Q: 审核需要多久？
**A**:
- 首次审核：通常 1-3 天
- 更新审核：通常 1-2 天
- 如有问题需要沟通，可能延长至 1 周

### Q: 应用是免费的，还需要填写银行信息吗？
**A**: 需要。即使是免费应用，也需要完成 Apple Developer 协议和银行信息填写。
