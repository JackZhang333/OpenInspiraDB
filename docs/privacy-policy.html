隐私政策

最后更新日期：2026年3月18日

引言

意图集（"我们"或"本应用"）尊重并保护所有使用服务用户的个人隐私权。本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息。

信息收集

我们收集的信息

本地存储的数据：

  • 您导入的图片文件（存储在您的本地设备）
  • 图片的 AI 分析结果（描述、标签等元数据）
  • 应用设置和偏好

可选的云端服务：

  • 仅在您主动配置 API Key 并启用 AI 分析时，图片会上传至第三方 AI 服务（智谱 AI 等）
  • 我们不存储您的 API Key，使用系统安全存储（macOS Keychain）加密保存

我们不收集的信息

  • 我们不收集任何个人身份信息
  • 我们不会追踪您的使用行为
  • 我们不会上传您的图片到我们的服务器

数据存储

本地优先

意图集采用"本地优先"的设计理念：

  • 所有图片数据存储在您的 Mac 本地
  • 数据库文件位于：~/Library/Application Support/意图集/
  • 您可以随时导出或删除所有数据

API Key 安全

  • 您的 API Key 使用 macOS 系统安全存储加密保存
  • 密钥不会以明文形式存储在磁盘上
  • 仅用于调用 AI 分析服务

数据使用

AI 图片分析

当您启用 AI 分析功能时：

  • 图片会上传至您配置的第三方 AI 服务提供商
  • 分析结果（描述、标签）存储在本地
  • 原始图片不会被第三方保留（依据各 AI 服务商的隐私政策）

我们不会

  • 将您的数据出售给第三方
  • 使用您的图片训练 AI 模型
  • 分析或扫描您的图片内容用于广告目的

数据安全

我们采取以下措施保护您的数据：

  • 所有数据处理在本地完成
  • 应用使用沙盒机制运行
  • 不访问网络（除用户主动启用的 AI 分析服务外）

您的权利

您可以随时：

  • 导出所有图片和元数据
  • 删除应用及所有相关数据
  • 修改或删除 API Key 设置

儿童隐私

本应用不面向 13 岁以下儿童。我们不会故意收集儿童的个人信息。

政策更新

我们可能会不时更新本隐私政策。更新后的政策将在应用内和网站上公布。
