# 国际化 (i18n) 使用指南

## 概述

应用支持中文和英文两种语言，基于 `react-i18next` 实现。

## 文件结构

```
renderer/src/i18n/
├── config.js          # i18n 配置
├── index.js           # 导出入口
└── locales/
    ├── zh-CN.json     # 中文翻译
    └── en.json        # 英文翻译
```

## 在组件中使用

### 基础用法

```javascript
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();

  return (
    <div>
      <h1>{t('app.title')}</h1>
      <p>{t('sidebar.import')}</p>
    </div>
  );
}
```

### 带参数的翻译

```javascript
// 翻译键: "selectedCount": "已选 {{count}} 个标签"
t('sidebar.selectedCount', { count: 5 }); // "已选 5 个标签"
```

### 切换语言

```javascript
import { useTranslation } from 'react-i18next';

function LanguageSwitcher() {
  const { i18n } = useTranslation();

  const toggleLanguage = () => {
    const newLang = i18n.language === 'zh-CN' ? 'en' : 'zh-CN';
    i18n.changeLanguage(newLang);
    localStorage.setItem('language', newLang);
  };

  return (
    <button onClick={toggleLanguage}>
      {i18n.language === 'zh-CN' ? 'English' : '中文'}
    </button>
  );
}
```

## 添加新翻译

1. 在 `zh-CN.json` 和 `en.json` 中添加对应的键值
2. 键名使用小驼峰命名法
3. 按功能模块组织键名（sidebar, detailPanel, workspace, errors, common）

示例：

```json
// zh-CN.json
{
  "sidebar": {
    "newFeature": "新功能"
  }
}

// en.json
{
  "sidebar": {
    "newFeature": "New Feature"
  }
}
```

## 翻译键命名规范

| 模块 | 用途 |
|-----|------|
| `app.*` | 应用级文本 |
| `sidebar.*` | 侧边栏相关 |
| `detailPanel.*` | 详情面板 |
| `workspace.*` | 工作区（搜索、筛选）|
| `errors.*` | 错误消息 |
| `common.*` | 通用操作（保存、取消、删除等）|

## 语言检测优先级

1. 用户手动选择的语言（保存在 localStorage）
2. 系统语言（navigator.language）
3. 默认中文

## 支持的浏览器语言映射

- `zh-CN`, `zh-TW`, `zh-HK`, `zh` → 中文
- `en-US`, `en-GB`, `en` → 英文
- 其他 → 默认中文

## AI 多语言支持

### 图片分析（AI 生成标签和描述）

AI 分析服务根据当前语言设置生成对应语言的内容：

| 语言 | 描述语言 | 标签语言 |
|-----|---------|---------|
| 中文 (zh-CN) | 简体中文 | 中文标签 |
| 英文 (en) | English | English Tags |

**实现机制：**
1. 前端切换语言时，调用 `window.inspira.setSetting('language', newLang)` 保存到数据库
2. AI 服务 (`zhipu-ai.js`) 读取 `language` 设置
3. 根据语言构建不同的系统提示词（system prompt）
4. AI 返回对应语言的标签和描述

### 标签整理（Tag Organization）

标签整理功能同样支持多语言：
- 中文模式下：整理建议和标签名称为中文
- 英文模式下：整理建议和标签名称为英文

**注意事项：**
- 已有标签（中文）不会因切换语言而自动翻译
- 新导入的图片会根据当前语言设置生成对应语言的标签
- 预设标签词库在 AI 提示中作为参考，AI 会根据语言生成对应版本
