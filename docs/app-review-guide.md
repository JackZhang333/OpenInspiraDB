# Mac App Store 审核指南

## 审核前自查清单

### 功能完整性
- [ ] 应用可以正常启动，无崩溃
- [ ] 所有声明的功能都已实现
- [ ] 图片导入功能正常
- [ ] AI 分析功能正常
- [ ] 搜索功能正常
- [ ] 导出功能正常
- [ ] 删除功能正常

### 内容合规
- [ ] 不包含色情、暴力、仇恨内容
- [ ] 不包含误导性信息
- [ ] 不包含未授权的商业内容
- [ ] 不包含测试/占位内容（如 lorem ipsum）

### 元数据准备
- [ ] App 名称正确（意图集）
- [ ] 描述准确反映了应用功能
- [ ] 关键词相关且合规
- [ ] 截图展示真实功能
- [ ] 隐私政策 URL 有效
- [ ] 支持 URL 有效

## 常见审核问题及应对

### 1. AI 功能相关

**可能的问题：**
> "您的应用使用 AI 功能，请说明 AI 模型的来源和数据处理方式。"

**应对策略：**
- 明确说明使用第三方 AI 服务（智谱 AI）
- 强调仅在应用执行 AI 分析时才上传图片
- 说明原始图片不会被保留

**审核备注写法：**
```
此应用的 AI 分析功能使用第三方服务（智谱 AI）。
图片仅在分析时上传至第三方服务，分析结果存储在本地。
我们不在服务器上存储用户图片或分析结果。
```

### 2. 隐私和数据安全

**可能的问题：**
> "请说明应用如何处理用户数据。"

**应对策略：**
- 强调"本地优先"架构
- 提供详细的隐私政策
- 说明数据存储位置

**关键点：**
- 所有图片存储在用户设备本地
- 不上传到开发者服务器
- 数据目录位于应用本地 `userData`

### 3. 应用功能

**可能的问题：**
> "您的应用似乎功能过于简单。"

**应对策略：**
- 强调 AI 分析和语义搜索的独特价值
- 说明目标用户群体（设计师、创意工作者）
- 展示与其他图库管理工具的区别

**差异化说明：**
```
意图集不仅是一个图片浏览器，它结合了 AI 技术：
1. 自动分析图片内容生成描述
2. 支持自然语言语义搜索
3. 本地化管理保护隐私
这些功能针对创意工作者的特定需求设计。
```

### 4. 沙盒和权限

**可能的问题：**
> "应用请求了不必要的权限。"

**当前权限说明：**
- **文件访问**：需要访问用户选择的文件夹进行导入
- **网络访问**：仅在启用 AI 分析时需要访问第三方 API

**应对：**
- 确保 entitlements 配置正确
- 只请求必要的权限
- 在描述中说明权限用途

### 5. 外部购买和支付

**可能的问题：**
> "应用不能引导用户使用外部支付方式。"

**应对：**
- 当前版本没有付费功能，无需担心
- 如未来添加付费功能，使用 App Store 内购

## 审核加速技巧

### 1. 详细的审核备注

在 App Store Connect 的"审核备注"字段提供：

```
【测试账号】
无需登录即可使用基础功能。

【AI 功能说明】
AI 分析使用第三方服务，仅在分析时上传图片。
分析结果与库内图片副本保存在本地。

【功能测试指南】
1. 导入图片：点击侧边栏"导入图片"按钮
2. 查看 AI 分析：导入后等待几秒，在详情面板查看
3. 语义搜索：在顶部搜索框输入描述性文字
4. 标签筛选：点击侧边栏任意标签

【特殊说明】
- 首次导入可能需要等待 AI 分析完成
- 分析时间取决于图片数量和大小
- 数据存储于应用本地 `userData` 目录，当前直装版默认位于 ~/Library/Application Support/InspiraDB/
```

### 2. 演示视频（可选）

如果功能复杂，可以上传演示视频：
- 时长：30-60 秒
- 展示核心功能流程
- 无需配音，可加文字说明

### 3. 联系信息

确保提供的联系邮箱：
- 可以正常接收邮件
- 及时回复审核问题
- 最好是公司域名邮箱

## 审核时间线

### 正常流程
1. **提交审核**：1-2 天进入审核状态
2. **正在审核**：通常 1-3 天
3. **等待发布**：审核通过后立即发布或按设定时间

### 加速审核
如需加速审核：
- 在 App Store Connect 申请"紧急审核"
- 说明理由（如修复严重 bug）
- 每年限用 2 次

## 审核被拒常见原因

### 技术问题
- 应用崩溃或无法启动
- 功能与描述不符
- 存在明显的 UI/UX 问题

### 内容问题
- 包含未授权的内容
- 存在误导性信息
- 包含测试数据

### 合规问题
- 隐私政策不完整
- 未提供必要的用户协议
- 违反沙盒规则

### 元数据问题
- 截图与功能不符
- 描述不准确
- 关键词滥用

---

## 被拒后的应对

### 步骤 1：仔细阅读拒审原因
- 理解具体问题
- 查看苹果提供的截图或日志

### 步骤 2：针对性修复
- 不要争辩，直接修复问题
- 如不理解，礼貌询问详情

### 步骤 3：回复审核团队
```
感谢您的反馈。

我们已经修复了以下问题：
1. [具体问题 1] - [修复方式]
2. [具体问题 2] - [修复方式]

请重新审核，谢谢！
```

### 步骤 4：重新提交
- 更新版本号
- 在"送审备注"说明已修复
- 重新提交审核

## 总结

提高审核通过率的关键：
1. **功能完整且稳定** -  thoroughly test before submission
2. **描述准确清晰** - 避免夸大或误导

4. **及时响应** - 快速回复审核团队的问题
